# Random Flash

**Category:** Non-Reactive

## Settings

### hit_color

- Type: `validate_color`
- Default: `#FFFFFF`
- Description: Hit color

### hit_duration

- Type: `All`
- Default: `0.5`
- Description: Hit duration

### hit_probability_per_sec

- Type: `All`
- Default: `0.1`
- Description: Probability of hit per second

### hit_relative_size

- Type: `All`
- Default: `10`
- Description: Hit size relative to LED strip
