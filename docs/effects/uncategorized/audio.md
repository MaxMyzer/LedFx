# audio

## Settings

### pitch_method

- Type: `In`
- Default: `yinfft`
- Description: Method to detect pitch

### tempo_method

- Type: `str`
- Default: `default`

### onset_method

- Type: `In`
- Default: `hfc`
- Description: Method used to detect onsets

### pitch_tolerance

- Type: `All`
- Default: `0.8`
- Description: Pitch detection tolerance
