# twod

## Settings

### flip_horizontal

- Type: `bool`
- Default: `False`
- Description: flip the image horizontally

### flip_vertical

- Type: `bool`
- Default: `False`
- Description: flip the image vertically

### rotate

- Type: `All`
- Default: `0`
- Description: 90 Degree rotations

### test

- Type: `bool`
- Default: `False`
- Description: ignore audio input

### dump

- Type: `bool`
- Default: `False`
- Description: dump image
