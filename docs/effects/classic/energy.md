# Energy

**Category:** Classic

## Settings

### blur

- Type: `All`
- Default: `4.0`
- Description: Amount to blur the effect

### mirror

- Type: `bool`
- Default: `True`
- Description: Mirror the effect

### color_cycler

- Type: `bool`
- Default: `False`
- Description: Change colors in time with the beat

### color_lows

- Type: `validate_color`
- Default: `#FF0000`
- Description: Color of low, bassy sounds

### color_mids

- Type: `validate_color`
- Default: `#00FF00`
- Description: Color of midrange sounds

### color_high

- Type: `validate_color`
- Default: `#0000FF`
- Description: Color of high sounds

### sensitivity

- Type: `All`
- Default: `0.6`
- Description: Responsiveness to changes in sound

### mixing_mode

- Type: `In`
- Default: `additive`
- Description: Mode of combining each frequencies' colors
