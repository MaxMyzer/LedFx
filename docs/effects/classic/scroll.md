# Scroll

**Category:** Classic

## Settings

### blur

- Type: `All`
- Default: `3.0`
- Description: Amount to blur the effect

### mirror

- Type: `bool`
- Default: `True`
- Description: Mirror the effect

### speed

- Type: `All`
- Default: `3`
- Description: Speed of the effect

### decay

- Type: `All`
- Default: `0.97`
- Description: Decay rate of the scroll

### threshold

- Type: `All`
- Default: `0.0`
- Description: Cutoff for quiet sounds. Higher -> only loud sounds are detected

### color_lows

- Type: `validate_color`
- Default: `#FF0000`
- Description: Color of low, bassy sounds

### color_mids

- Type: `validate_color`
- Default: `#00FF00`
- Description: Color of midrange sounds

### color_high

- Type: `validate_color`
- Default: `#0000FF`
- Description: Color of high sounds
