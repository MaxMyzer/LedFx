# Scan and Flare

**Category:** Classic

## Settings

### blur

- Type: `All`
- Default: `3.0`
- Description: Amount to blur the effect

### mirror

- Type: `bool`
- Default: `False`
- Description: Mirror the effect

### bounce

- Type: `bool`
- Default: `True`
- Description: bounce the scan

### scan_width

- Type: `All`
- Default: `30`
- Description: Width of scan eye in %

### speed

- Type: `All`
- Default: `50`
- Description: Scan base % per second

### sparkles_max

- Type: `All`
- Default: `10`
- Description: max number of sparkles

### sparkles_size

- Type: `All`
- Default: `0.1`
- Description: of scan size 

### sparkles_time

- Type: `All`
- Default: `1.0`
- Description: secs to die off

### sparkles_threshold

- Type: `All`
- Default: `0.6`
- Description: level to trigger

### color_scan

- Type: `validate_color`
- Default: `#FF0000`
- Description: Color of scan

### frequency_range

- Type: `In`
- Default: `Lows (beat+bass)`
- Description: Frequency range for the beat detection

### multiplier

- Type: `All`
- Default: `3.0`
- Description: Speed impact multiplier

### color_intensity

- Type: `bool`
- Default: `True`
- Description: Adjust color intensity based on audio power

### use_grad

- Type: `bool`
- Default: `False`
- Description: Use colors from gradient selector
