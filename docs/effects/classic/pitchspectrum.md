# Pitch Spectrum

**Category:** Classic

## Settings

### blur

- Type: `All`
- Default: `1.0`
- Description: Amount to blur the effect

### mirror

- Type: `bool`
- Default: `True`
- Description: Mirror the effect

### fade_rate

- Type: `All`
- Default: `0.15`
- Description: Rate at which notes fade

### responsiveness

- Type: `All`
- Default: `0.15`
- Description: Responsiveness to note changes
