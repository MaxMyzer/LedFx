# Rain

**Category:** Classic

## Settings

### mirror

- Type: `bool`
- Default: `True`
- Description: Mirror the effect

### lows_color

- Type: `validate_color`
- Default: `white`
- Description: color for low sounds, ie beats

### pulse_strip

- Type: `In`
- Default: `Off`
- Description: Pulse the entire strip to the beat

### mids_color

- Type: `validate_color`
- Default: `red`
- Description: color for mid sounds, ie vocals

### high_color

- Type: `validate_color`
- Default: `blue`
- Description: color for high sounds, ie hi hat

### lows_sensitivity

- Type: `All`
- Default: `0.1`
- Description: Sensitivity to low sounds

### mids_sensitivity

- Type: `All`
- Default: `0.05`
- Description: Sensitivity to mid sounds

### high_sensitivity

- Type: `All`
- Default: `0.1`
- Description: Sensitivity to high sounds

### raindrop_animation

- Type: `In`
- Description: Droplet animation style
