# PlasmaWled2d

**Category:** Matrix

## Settings

### frequency_range

- Type: `In`
- Default: `Lows (beat+bass)`
- Description: Frequency range for the beat detection

### speed

- Type: `All`
- Default: `128`
- Description: Speed multiplier

### stretch_horizontal

- Type: `All`
- Default: `128`
- Description: Smaller is less block in horizontal dimension

### stretch_vertical

- Type: `All`
- Default: `128`
- Description: Smaller is less block in vertical dimension

### size_multiplication

- Type: `All`
- Default: `0.4`
- Description: Sound to size multiplier

### speed_multiplication

- Type: `All`
- Default: `0.4`
- Description: Sound to speed multiplier
