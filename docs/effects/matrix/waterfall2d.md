# Waterfall

**Category:** Matrix

## Settings

### center

- Type: `bool`
- Default: `False`
- Description: Center the waterfall

### max_vs_mean

- Type: `bool`
- Default: `False`
- Description: Use max or mean value for bar size

### bands

- Type: `All`
- Default: `16`
- Description: Number of frequency bands

### drop_secs

- Type: `All`
- Default: `3.0`
- Description: Seconds for the waterfall to drop from the top to bottom of the matrix
