# Flame

**Category:** Matrix

## Settings

### spawn_rate

- Type: `All`
- Default: `0.5`
- Description: Particles spawn rate

### velocity

- Type: `All`
- Default: `0.3`
- Description: Trips to top per second

### intensity

- Type: `All`
- Default: `0.5`
- Description: Application of the audio power input

### blur_amount

- Type: `All`
- Default: `2`
- Description: Blur radius in pixels

### low_band

- Type: `validate_color`
- Default: `#FF0000`
- Description: low band flame

### mid_band

- Type: `validate_color`
- Default: `#00FF00`
- Description: mid band flame

### high_band

- Type: `validate_color`
- Default: `#0000FF`
- Description: high band flame
