# Multicolor Bar

**Category:** BPM

## Settings

### mode

- Type: `In`
- Default: `wipe`
- Description: Choose from different animations

### ease_method

- Type: `In`
- Default: `linear`
- Description: Acceleration profile of bar

### color_step

- Type: `All`
- Default: `0.125`
- Description: Amount of color change per beat
