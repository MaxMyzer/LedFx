# Pixels

**Category:** Diagnostic

## Settings

### speed

- Type: `All`
- Default: `20.0`
- Description: Locked to 20 fps

### step_period

- Type: `All`
- Default: `1.0`
- Description: Time between each pixel step to light up

### pixels

- Type: `All`
- Default: `1`
- Description: Number of pixels each step

### background_color

- Type: `validate_color`
- Default: `#000000`
- Description: Background color

### pixel_color

- Type: `validate_color`
- Default: `#FFFFFF`
- Description: Pixel color to light up

### build_up

- Type: `bool`
- Default: `False`
- Description: Single or building pixels

### color_blend

- Type: `bool`
- Default: `False`
- Description: Restart effect on color change, for transitions
