# Metro

**Category:** Diagnostic

## Settings

### pulse_period

- Type: `All`
- Default: `1`
- Description: Time between flash in seconds

### pulse_ratio

- Type: `All`
- Default: `0.3`
- Description: Flash to blank ratio

### steps

- Type: `All`
- Default: `4`
- Description: Steps of pattern division to loop

### background_color

- Type: `validate_color`
- Default: `#000000`
- Description: Background color

### flash_color

- Type: `validate_color`
- Default: `#FFFFFF`
- Description: Flash color

### capture

- Type: `bool`
- Default: `True`
- Description: graph capture, on to start, off to dump

### cpu_secs

- Type: `All`
- Default: `1.0`
- Description: Window over which to measure CPU usage
