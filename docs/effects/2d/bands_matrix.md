# Bands Matrix

**Category:** 2D

## Settings

### band_count

- Type: `All`
- Default: `6`
- Description: Number of bands

### mirror

- Type: `bool`
- Default: `False`
- Description: Mirror the effect

### flip_gradient

- Type: `bool`
- Default: `False`
- Description: Flip Gradient

### flip_horizontal

- Type: `bool`
- Default: `False`
- Description: Flip horizontally
